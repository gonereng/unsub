Database Schema — PostgreSQL via Prisma

7 core tables powering all 20 features. Each table has one clear responsibility.

User

id            String  @id @default(cuid())
email         String  @unique
name          String?
image         String?
createdAt     DateTime @default(now())
updatedAt     DateTime @updatedAt

Account

id                  String  @id @default(cuid())
userId              String
provider            String   @default("google")  # google | microsoft
providerAccountId   String
accessToken         String   @encrypted?
refreshToken        String   @encrypted?
expiresAt           Int?
scope               String?
tokenType           String?
active              Boolean  @default(true)       # kill switch

@@unique([provider, providerAccountId])
@@index([userId])

Tokens encrypted at rest. Multiple accounts per user = multi-account support. active=false = kill switch.

Subscription

id                  String     @id @default(cuid())
accountId           String
senderName          String?
senderEmail         String
listUnsubscribe     String?         # URL or mailto:
listUnsubscribePost String?         # HTTP POST endpoint
lastEmailAt         DateTime?
frequency           String?         # daily, weekly, monthly
category            String?         # shopping, news, finance, social
isWhitelisted       Boolean  @default(false)
isBlocked           Boolean  @default(false)
firstDetectedAt     DateTime @default(now())

@@unique([accountId, senderEmail])
@@index([accountId])
@@index([category])

Unique per account+sender. Category auto-assigned during scanning. Block/whitelist flags are mutual toggles.

ActionLog

id              String   @id @default(cuid())
subscriptionId  String
action          String   # unsubscribed | blocked | whitelisted | rolled_up
metadata        Json?    # extra context (e.g., fallback used, warning shown)
createdAt       DateTime @default(now())

@@index([subscriptionId])
@@index([createdAt])

Action history for the Undo tab and audit trail.

DigestConfig

id          String  @id @default(cuid())
userId      String  @unique
frequency   String  @default("daily")   # daily | weekly
time        String  @default("08:00")   # HH:mm
dayOfWeek   Int?    @default(0)          # 0=Sun ... 6=Sat (for weekly)
isEnabled   Boolean @default(true)

@@index([userId])

Digest

id          String   @id @default(cuid())
userId      String
sentAt      DateTime @default(now())
emailCount  Int
emails      Json?    # { subject, sender, snippet, url }[]

@@index([userId, sentAt])

Archived digest records for analytics "Emails Rolled Up" metric.

ScanJob

id          String   @id @default(cuid())
accountId   String
status      String   # pending | scanning | completed | failed
startedAt   DateTime?
completedAt DateTime?
newCount    Int      @default(0)
error       String?

@@index([accountId, startedAt])

Tracks each inbox scan to avoid duplicate work and report progress.

Entity Relationships
