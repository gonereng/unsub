Key Components

Subscription List
Sortable data table. Columns: checkbox, sender name, frequency badge, last email, actions (unsubscribe/block/whitelist/rollup). Click row to expand preview.
Category Tabs
All | News | Shopping | Finance | Social | Other. Each tab filters the list. Category auto-assigned from sender domain + email content keywords.
Rich Preview Panel
Click a row → slide-in panel shows subject line, sender, snippet of last email. Helps user remember what the newsletter is before acting.
Action Log (Undo Tab)
Bottom nav "Undo" shows history. Each entry: action + sender + timestamp + "Undo" button. Undo a block → remove provider filter. Undo unsubscribe → just re-add to list (can't unsend).
